# Ronda · Coevaluación

Prototipo web para organizar la coevaluación entre alumnos.

## Probarlo

Abre `index.html` en un navegador. No requiere instalación ni servidor.

La vista de administración permite crear cursos, registrar alumnos y correos, configurar preguntas y editar notas. La vista pública permite elegir curso y alumno, completar una verificación de demostración y enviar una coevaluación. Los datos se guardan en el almacenamiento local del navegador.

## Limitaciones de esta maqueta

- El código de confirmación es fijo (`246810`); no se envía ningún correo.
- La administración no tiene autenticación. No introduzcas datos personales reales ni publiques esta versión como servicio.
- Para uso real hace falta un backend con inicio de sesión de administrador, envío y caducidad de códigos por correo, almacenamiento centralizado y controles de privacidad.
